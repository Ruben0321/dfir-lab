# dfir-lab

Notes, labs and scripts from my digital forensics and incident response practice.

## Folders

- `00-foundations`: Linux, networking, Windows internals, scripting
- `01-windows-artifacts`: registry, Prefetch, Amcache, ShellBags, LNK, event logs
- `02-memory`: memory analysis with Volatility 3
- `03-disk`: file systems, carving, timelines
- `04-incident-response`: triage, log analysis, playbooks
- `05-detection`: Sigma and YARA rules
- `writeups`: one folder per lab or CTF case (template in `writeups/_template.md`)
- `cheatsheets`: quick references
- `scripts`: small Python and Bash tools

Everything here comes from public labs, CTFs or images I made myself. No real case data.
