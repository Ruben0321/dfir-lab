#Linux cheatsheets
commands i use in the linux terminal
##List
`cd`-  change between directories 
`ls`- list the files in a folder 
`find`- search for files and  folders
`cat`- show the content of a file 
`tree`- show  directories in tree format 
`du`- estimate the file space usage
## ls

- `ls -a` → show hidden files
- `ls -l` → long format (permissions, owner, size, date)
- `ls -t` → sort by modification time, newest first
- `ls -r` → reverse the order
- `ls -la` → all files in long format
- `ls -ltr` → long format, oldest first (newest at the bottom)
